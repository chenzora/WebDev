Web Technologies

HTML

HTML stands for, Hyper Text Markup Language, and it is used to make webpages.
Some popular webpages that use HTML is www.Google.com and www.Amazon.com.
And unlike Python or Javascript, HTML is a markup language, not a programming language.

CSS

CSS stands for, Cascading Style Sheets, which is the tool that makes websites look good.
While HTML adds the text and pictures to a page, CSS adds the colors, fonts, and layouts.
It lets you change how a webpage looks/the design of a whole website using just one file.

JavaScript

JavaScript is a programming language that makes websites interactive and alive.
While HTML adds the text and CSS adds the style, JavaScript lets you add moving parts like pop-ups, search bars, and video players.
It runs directly inside your web browser, which means it can change things on the page instantly when someone clicks a button or link.

Python

Python is a programming language that is easy to read and write.
Unlike more complicated languages, it uses simple, English words, making it the perfect choice for beginners learning how to code.
However, people use Python for all kinds of big jobs, including building websites, analyzing data, creating artificial intelligence programs, and most importantly making games!
