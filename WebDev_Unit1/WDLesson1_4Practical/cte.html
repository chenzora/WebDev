Computer Programming and Web Design


he Computer Programming and Web Design Career and Technical Education (CTE) pathway
introduces students to the fast-paced world of software engineering, coding, and digital
innovation. Through hands-on, project-based learning, students gain a comprehensive
foundation in both front-end and back-end development. They learn to write powerful
algorithms, build responsive, mobile-firstwebsites from scratch, and create functional
applications using industry-standard languages like HTML5, CSS JavaScript, Python, and Java.
